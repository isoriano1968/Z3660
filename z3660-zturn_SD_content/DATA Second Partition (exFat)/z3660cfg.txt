# AMIX main-RAM window size in MiB (only meaningful with amix_mode YES).
# Default 16 -- the historical size, unchanged when this key is absent.
# Valid 1..128. The window starts at guest $08000000 and must stop below $10000000,
# where the RTG/ethernet combo board lives; a larger value is REFUSED at boot (loudly,
# on the serial console) and falls back to 16 -- it is never silently truncated.
# 64 is the recommended cap for a shipping config: past the AMIX kernel's describable-RAM
# ceiling the boot dies SILENTLY, with no banner and no console output at all. The 4KB-page
# 68040 kernel reaches further than the 2KB-page 68030 one. See docs/AMIX.md.

# Emulator service cadence: emulated instructions between interrupt-service polls.

# Select your hdf files (from hdf0 to hdf19). Use isoX instead of hdfX to use ISO CD ROM files.
#
# *** isoN: the slot number MUST equal the SCSI target number ***
#
# hdfN and isoN both fill IMAGE SLOT N. isoN additionally flags "slot N is a CD",
# but the flag is consumed PER SCSI TARGET, not per slot: target t is presented as
# a read-only 2048-byte CD-ROM (device type 0x05) iff slot number t was declared
# with isoN. The scsiN line that assigns the image is not consulted for the flag.
#
# So the ONLY reliable way to attach a CD image to SCSI target t is:
#
#     isoN <file>     with N == t
#     scsiN t         (same number on both lines)
#
# e.g. a CD on target 2:   iso2 iso/AmigaOS39.iso
#                          scsi2 2
#
# Get it wrong and it fails quietly, in both directions: the image is mounted as
# a plain read-write RDB hard disk (its ISO filesystem will not be found), AND any
# unrelated image that happens to sit on target N is presented as a CD-ROM.
# The iso4 / scsi4 pair below shows the CORRECT form: the ISO's slot number and
# its scsiN target are the SAME (4). Upstream's shipped example paired iso6 with
# scsi4 6 - slot 6 flagged, target 4 assigned - which does NOT produce a working
# CD. Only slots 0-6 can carry the flag at all; iso7 and above are refused.
hdf0 hdf/a4000.hdf
hdf1 hdf/Daten5_PFS3.hdf
hdf2 hdf/Work.hdf
hdf3 hdf/temp_1G_PFS3.hdf
#hdf4 hdf/hd0.hda
hdf5 hdf/Programs.hdf
iso4 iso/AmigaOS39.iso
